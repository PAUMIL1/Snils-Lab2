# Лабораторная работа: Проверка и поиск синтаксически корректных СНИЛС

Консольное приложение на Python для валидации и поиска номеров СНИЛС (формат `XXX-XXX-XXX YY` и `XXX-XXX-XXX-YY`) в пользовательском вводе, текстовых файлах и на веб-страницах по URL.

## Установка и запуск
```bash
pip install -r requirements.txt
python main.py
```

## Запуск модульных тестов
```bash
python -m unittest test_snils.py -v
```
